# Caleb Burnham — MEGR 2157 Portfolio
## Part 1, Task B: Product Analysis — Medium Binder Clip

### a. Primary Engineering Function
The primary engineering function of a binder clip is to apply a constant clamping force across a stack of material using spring tension to keep the sheets from sliding.

### b. Governing Model & Assumptions
**Key Assumption:** The spring steel remains in its linear elastic range, meaning opening the clip never bends the metal permanently.
